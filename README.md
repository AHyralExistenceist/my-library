# My Library

`서재 실행.cmd`를 실행한 뒤 브라우저에서 http://127.0.0.1:4173 을 엽니다. Node.js가 필요합니다(별도 설치 필요). 실행 창을 닫으면 서버가 종료됩니다. 외부 패키지, 인터넷 연결, 계정은 필요하지 않습니다.

1. 왼쪽 아래 **저장 공간 설정**에서 전용 폴더를 선택합니다.
2. **책 추가**를 누르고 제목, 작가, 독서 상태, 별점, 서평을 입력합니다.
3. 표지 이미지를 선택하고 **-complete** 또는 닫기(×)를 누릅니다. 이미지는 긴 변 최대 1,000px로 저장됩니다.
4. 책장 표지를 클릭하면 기록을 수정하거나 삭제할 수 있습니다.
5. 다시 방문하면 마지막 저장 폴더와 서재가 자동 복원됩니다. **저장 공간 설정**에서 전체 경로를 확인하거나 다른 폴더를 선택할 수 있습니다.

선택한 폴더의 `my-library.json`에 표지를 포함한 전체 기록이 저장됩니다. 다른 컴퓨터로 이 파일을 옮겨 같은 방식으로 열 수 있습니다. 기존 서재 파일이 있는 폴더를 선택하면 해당 서재를 열고, 비어 있는 폴더를 선택하면 현재 서재의 복사를 제안합니다. 원래 폴더는 변경하지 않습니다.

Windows 또는 Mac의 폴더 선택 창으로 지정한 전체 경로는 이 앱 폴더의 `.local-storage.json`에 기억됩니다. 로컬 서버가 선택한 폴더의 기록 파일을 읽고 씁니다. 새로고침하거나 서버를 재실행하면 같은 서재를 엽니다. 파일 가져오기/내려받기도 사용할 수 있습니다. 같은 서재를 여러 탭에서 동시에 편집하지 마세요.

서재 데이터는 이 컴퓨터 안에서만 처리됩니다. 로컬 서버는 이 컴퓨터의 127.0.0.1에서 화면을 제공하고, 사용자가 선택한 폴더의 서재 파일만 읽고 씁니다. 기록은 외부 서버로 전송되지 않습니다. 클라우드 동기화 폴더를 선택하면 해당 폴더의 동기화 정책이 적용됩니다. 저장은 **-complete**, 문장 저장, 닫기(×)를 누를 때 수행됩니다. 사용자 지정 책 순서는 드래그 후 자동 저장됩니다.
